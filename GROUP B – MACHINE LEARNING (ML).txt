PRACTICAL 6 – Bank Customer Churn Prediction using Neural Networks
1. Aim

Build a Neural Network-based classifier to predict whether a bank customer will leave the bank within the next six months.

2. What is Customer Churn?

Customer Churn refers to the situation in which a customer stops using the services of a company.

In banking, it means that a customer closes their account or leaves the bank.

Example:

If a bank has 10,000 customers and 1,000 customers leave, the churn rate is:

Churn Rate = (1000 / 10000) × 100

Churn Rate = 10%.

3. What is Machine Learning?

Machine Learning is a branch of Artificial Intelligence that allows computers to learn patterns from data and make predictions without explicitly programming every rule.

4. What is Supervised Learning?

Supervised Learning is a type of Machine Learning in which the model learns from labelled data.

In this practical:

Input: Customer information.
Output: Whether the customer will leave or stay.
5. What is Classification?

Classification is a supervised learning technique used to predict categorical outputs.

Here, there are two classes:

0 = Customer stays.
1 = Customer leaves.
6. What is an Artificial Neural Network?

An Artificial Neural Network (ANN) is a Machine Learning model inspired by the human brain.

It consists of interconnected neurons organized into layers.

7. Layers of Neural Network

Input Layer:

Receives customer information such as age, balance and credit score.

Hidden Layer:

Processes the input data and learns patterns.

Output Layer:

Predicts whether the customer will leave or stay.

For binary classification, a sigmoid output is commonly used.

Formula:

16. What is an Activation Function?

An Activation Function determines the output of a neuron.

Common activation functions:

17. What is the Sigmoid Function?

Sigmoid converts an input into a value between 0 and 1.

Formula:

f(x) = 1 / (1 + e⁻ˣ)

The output can be interpreted as a predicted probability for the positive class.

For example:

0.85 → High predicted probability of churn.
0.20 → Low predicted probability of churn.

18. What is Loss Function?

A Loss Function measures the difference between actual and predicted outputs.

For binary classification, Binary Cross-Entropy is commonly used.

19. What is an Optimizer?

An Optimizer updates the neural network's weights and biases to reduce the loss.

Examples:

SGD.
RMSprop.
20. What is Accuracy?

Accuracy measures the percentage of correct predictions.

Accuracy = Correct Predictions / Total Predictions × 100.

21. What is a Confusion Matrix?

PRACTICAL 7 – Email Classification using KNN and SVM
1. Aim

Classify emails into Normal (Not Spam) and Abnormal (Spam) categories using K-Nearest Neighbour and Support Vector Machine algorithms and compare their performance.

2. What is Email Spam?

Email Spam refers to unwanted or unsolicited emails sent in bulk.

Examples:

Fake lottery messages.
Unwanted advertisements.
Fraudulent banking messages.
Phishing emails.
3. What is Binary Classification?

Binary Classification is a supervised learning problem in which the output contains only two classes.

In this practical:

0 = Not Spam.
1 = Spam.

The exact numerical encoding depends on the dataset.

4. What is K-Nearest Neighbour?

KNN is a supervised learning algorithm that classifies a new data point based on the majority class among its K nearest training points.

It commonly uses Euclidean distance.

5. Working of KNN
Choose the value of K.
Calculate distances from the new data point to training points.
Identify K nearest neighbours.
Find their majority class.
Assign that class to the new email.
6. What is Euclidean Distance?

It measures the straight-line distance between two points.

Formula:

d = √[(x₂ − x₁)² + (y₂ − y₁)²]

7. What is SVM?

Support Vector Machine is a supervised learning algorithm that finds an optimal decision boundary to separate different classes.

8. What is Hyperplane?

A Hyperplane is a decision boundary that separates different classes.

In two dimensions, it is a line.

9. What are Support Vectors?

Support Vectors are the data points closest to the separating hyperplane.

They determine the position of the decision boundary and its margin.

10. What is Margin?

Margin is the distance between the separating hyperplane and the nearest data points from each class.

SVM attempts to maximize this margin.

11. What is a Kernel?

A Kernel is a mathematical function used by SVM to handle nonlinear classification problems.

Common kernels:

Linear.
Polynomial.
RBF.
Sigmoid.
12. What is Text Vectorization?

Text Vectorization converts textual information into numerical features that Machine Learning algorithms can process.

Common techniques:

Bag of Words.
TF-IDF.
Word Embeddings.
13. What is TF-IDF?

TF-IDF stands for Term Frequency–Inverse Document Frequency.

It measures how important a word is in a document compared with the entire collection of documents.

It gives greater importance to words that are frequent in a particular document but less common across all documents.

15. Difference between KNN and SVM

KNN:

Distance-based algorithm.
Lazy learning.
Uses nearest neighbours.
Prediction can become slow for large datasets.

SVM:

Finds an optimal decision boundary.
Uses support vectors.
Can handle nonlinear classification using kernels.
Can work well with high-dimensional text features.

Error Rate = 1 − Accuracy.

13. What is Recall?

Recall measures how many actual positive cases are correctly identified.

Formula:

Recall = TP / (TP + FN).

Recall is important because it measures the ability of the model to identify actual diabetic cases.

PRACTICAL 9 – K-Means or Hierarchical Clustering on Sales Data
1. Aim

Implement K-Means or Hierarchical Clustering on the sales_data_sample.csv dataset and determine the number of clusters using the Elbow Method.

2. What is Unsupervised Learning?

Unsupervised Learning is a type of Machine Learning in which the model learns patterns from unlabelled data.

There are no predefined output labels.

3. What is Clustering?

Clustering is the process of grouping similar data points together.

Data points in the same cluster should have similar characteristics.

4. What is K-Means Clustering?

K-Means is an unsupervised learning algorithm that divides data into K clusters.

Each cluster is represented by a centroid.

5. What is a Centroid?

A Centroid is the mean position of all data points belonging to a particular cluster.

It represents the centre of that cluster.

6. Working of K-Means

Suppose we want to divide customers into three groups.

K = 3.

Step 1: Select K = 3.

Step 2: Initialize three centroids.

Step 3: Calculate the distance between every data point and each centroid.

Step 4: Assign each data point to its nearest centroid.

Step 5: Recalculate centroids.

Step 6: Repeat until cluster assignments become stable.

7. What is the Elbow Method?

The Elbow Method is used to determine the suitable number of clusters in K-Means.

It plots:

X-axis: Number of clusters K.
Y-axis: WCSS.

The point where the reduction in WCSS starts slowing significantly is called the Elbow Point.

8. What is WCSS?

WCSS stands for Within-Cluster Sum of Squares.

It measures the total squared distance between data points and their respective cluster centroids.

Lower WCSS indicates more compact clusters.

9. What is Hierarchical Clustering?

Hierarchical Clustering is an unsupervised learning technique that creates a hierarchy of clusters.

It is represented using a Dendrogram.

10. Types of Hierarchical Clustering

Agglomerative Clustering:

Bottom-up approach.

Starts with individual data points and repeatedly merges the closest clusters.

Divisive Clustering:

Top-down approach.

Starts with all data points in one cluster and repeatedly divides them.

11. What is a Dendrogram?

A Dendrogram is a tree-like diagram that shows how clusters are merged or divided.

It helps determine the number of clusters.

12. What is Feature Scaling?

Feature Scaling transforms numerical features into comparable ranges.

It is important because clustering algorithms often use distance calculations.

13. Algorithm – K-Means
Start.

Handle missing values.
Scale the features.
Apply K-Means for different K values.
Calculate WCSS for each K.
Plot the Elbow Graph.
Select a suitable K.
Train the final K-Means model.
Assign cluster labels.
Visualize the clusters.
Stop.

A common K-Means implementation has approximate time complexity:

O(n × K × I × d)

Where:

n = Number of data points.

I = Number of iterations.
d = Number of features.

PRACTICAL 10 – Gradient Descent to Find Local Minima
1. Aim

Implement the Gradient Descent Algorithm to find the local minimum of a function.

Given:

y = (x + 3)²

Starting point:

x = 2.

2. What is Optimization?

Optimization is the process of finding the best possible solution by minimizing or maximizing a mathematical function.

In this practical, we want to minimize the function.

3. What is Gradient Descent?

Gradient Descent is an optimization algorithm that minimizes a function by repeatedly updating the input parameter in the direction opposite to the gradient.

4. What is Gradient?

A Gradient represents the direction and rate of the steepest increase of a function.

For a single-variable function, it is the derivative.

5. Given Function

y = (x + 3)²

Differentiate:

dy/dx = 2(x + 3).

At the minimum:

dy/dx = 0.

Therefore:

2(x + 3) = 0.

x = -3.

Minimum value:

y = (-3 + 3)² = 0.

Therefore, the minimum point is x = -3 and y = 0.

6. Gradient Descent Formula

New x = Old x − Learning Rate × Gradient.

x(new) = x(old) − α × f'(x).

Where:

α = Learning Rate.
f'(x) = Derivative of the function.
7. Working Example

Given:

x = 2.

Learning rate = 0.1.

Derivative:

f'(x) = 2(x + 3).

At x = 2:

f'(2) = 2(5) = 10.

Update:

x(new) = 2 − 0.1 × 10.

x(new) = 1.

The algorithm continues updating x.

It gradually approaches -3.

8. Algorithm
Start.
Define the function f(x) = (x + 3)².
Define its derivative f'(x) = 2(x + 3).
Initialize x = 2.
Select a learning rate.
Calculate the gradient.
Update x using the Gradient Descent formula.
Repeat until the gradient or change in x becomes sufficiently small.
Display the minimum point.
Stop.
9. What is Learning Rate?

Learning Rate controls the size of each update.

Too high: May overshoot the minimum or diverge.
Too low: Convergence may be slow.
Suitable value: Helps reach the minimum efficiently.
10. What is Convergence?

Convergence means the algorithm approaches a stable solution or minimum.

11. What is Local Minimum?

A Local Minimum is a point where the function value is lower than nearby points.

12. What is Global Minimum?

A Global Minimum is the lowest value of the function over its entire domain.

For the given function, x = -3 is both the local and global minimum.
