# CELL 1: IMPORT LIBRARIES

import pandas as pd
import matplotlib.pyplot as plt

from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler


# =====================================================
# CELL 2: READ DATASET
# =====================================================

data = pd.read_csv("sales_data_sample.csv", encoding="latin1")

print("Dataset Loaded Successfully")
print(data.head())

print("\nDataset Shape:", data.shape)


# =====================================================
# CELL 3: SELECT FEATURES
# =====================================================

# Select numerical sales-related columns
X = data[[
    "SALES",
    "QUANTITYORDERED",
    "PRICEEACH",
    "MSRP"
]]

print("\nSelected Features:")
print(X.head())


# =====================================================
# CELL 4: NORMALIZE DATA
# =====================================================

scaler = StandardScaler()

X_scaled = scaler.fit_transform(X)

print("\nData Normalized Successfully")


# =====================================================
# CELL 5: ELBOW METHOD
# =====================================================

wcss = []

# Calculate WCSS for different cluster values
for i in range(1, 11):

    kmeans = KMeans(
        n_clusters=i,
        random_state=42,
        n_init=10
    )

    kmeans.fit(X_scaled)

    wcss.append(kmeans.inertia_)

# Plot Elbow Graph
plt.plot(range(1, 11), wcss, marker="o")

plt.title("Elbow Method")
plt.xlabel("Number of Clusters (K)")
plt.ylabel("WCSS")

plt.show()


# =====================================================
# CELL 6: APPLY K-MEANS CLUSTERING
# =====================================================

# Select optimal number of clusters
kmeans = KMeans(
    n_clusters=3,
    random_state=42,
    n_init=10
)

# Train the model
kmeans.fit(X_scaled)

# Assign cluster labels
data["Cluster"] = kmeans.labels_

print("\nClustering Completed Successfully")


# =====================================================
# CELL 7: DISPLAY CLUSTER RESULTS
# =====================================================

print("\nCluster Assignments:")
print(data[["SALES", "QUANTITYORDERED", "Cluster"]].head(10))

print("\nNumber of Records in Each Cluster:")
print(data["Cluster"].value_counts())


# =====================================================
# CELL 8: VISUALIZE CLUSTERS
# =====================================================

plt.scatter(
    X_scaled[:, 0],
    X_scaled[:, 1],
    c=kmeans.labels_
)

plt.title("K-Means Clustering of Sales Data")

plt.xlabel("Sales (Normalized)")
plt.ylabel("Quantity Ordered (Normalized)")

plt.show()
#===== END OF PROGRAM=======

3. Important Theory for Viva
1. What is Clustering?

Clustering is an unsupervised machine learning technique used to group similar data points together.

2. What is Unsupervised Learning?

Unsupervised learning is a machine learning technique that discovers hidden patterns or groups in unlabelled data.

3. What is K-Means Clustering?

K-Means is an unsupervised algorithm that divides data into K clusters based on similarity and distance from cluster centroids.

4. Why is K-Means called K-Means?

Because it creates K clusters and calculates the mean, called the centroid, of each cluster.

5. What is a Cluster?

A cluster is a group of data points that are similar to each other.

6. What is a Centroid?

A centroid is the center point of a cluster, calculated as the mean of all data points belonging to that cluster.

7. What is the main objective of K-Means?

To group similar data points while minimizing the distance between data points and their respective cluster centroids.

8. What is the Elbow Method?

The Elbow Method determines a suitable number of clusters by plotting WCSS against different K values.

9. What is WCSS?

WCSS stands for Within-Cluster Sum of Squares. It measures the sum of squared distances between data points and their cluster centroids.

10. Why does WCSS decrease when K increases?

Because increasing the number of clusters generally brings data points closer to their respective centroids.

11. What is Hierarchical Clustering?

Hierarchical clustering is an unsupervised learning algorithm that creates a hierarchy of clusters by progressively merging or splitting groups.

12. What is Agglomerative Clustering?

Agglomerative clustering is a bottom-up approach. It starts with each data point as an individual cluster and progressively merges the closest clusters.

13. What is a Dendrogram?

A dendrogram is a tree-like diagram that represents the merging process of hierarchical clusters.

14. What is Ward's Method?

Ward's method merges clusters in a way that minimizes the increase in within-cluster variance.

15. Why did you select K = 3?

In the K-Means implementation, three clusters are selected based on the intended elbow point. The actual elbow graph should be checked to confirm this choice.

4. Difference Between K-Means and Hierarchical Clustering
K-Means Clustering	Hierarchical Clustering
Requires K beforehand.	Uses a hierarchy of clusters.
Uses centroids.	Uses distances between clusters.
Iteratively updates centroids.	Merges or splits clusters.
Generally faster for large datasets.	Can be computationally expensive.
Uses the Elbow Method to help select K.	Uses a dendrogram to help select clusters.
Suitable for relatively large datasets.	Often useful for understanding hierarchical relationships.
