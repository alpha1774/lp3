PRACTICAL 11 – Install MetaMask and Study Ether Spending per Transaction
1. Aim

Install MetaMask and study the amount of Ether spent during blockchain transactions.

2. What is MetaMask?

MetaMask is a cryptocurrency wallet that allows users to manage blockchain accounts and interact with Ethereum-compatible networks.

It is available as a browser extension and mobile application.

3. What is Cryptocurrency?

Cryptocurrency is a digital asset that uses cryptographic techniques to secure transactions.

Examples:

Bitcoin.
Ether.
Litecoin.
4. What is Ether?

Ether (ETH) is the native cryptocurrency of the Ethereum blockchain.

It is used for:

Paying transaction fees.
Transferring value.
Interacting with smart contracts.
5. What is Gas?

Gas is the unit used to measure the computational work required to execute operations on Ethereum.

6. What is Gas Fee?

Gas Fee is the amount paid for executing a transaction on Ethereum.

Basic formula:

Transaction Fee = Gas Used × Effective Gas Price.

7. What is Gwei?

Gwei is a denomination of Ether used to express gas prices.

1 Gwei = 0.000000001 ETH.

1 ETH = 1,000,000,000 Gwei.

8. What is a Transaction?

A transaction is a digitally signed instruction submitted to a blockchain network.

Examples:

Sending Ether.
Calling a smart contract.
Deploying a smart contract.
9. What is a Transaction Hash?

A Transaction Hash is a unique identifier used to locate and verify a transaction on the blockchain.

10. What is a Block Explorer?

A Block Explorer is a tool used to view blockchain information.

It displays:

Transactions.
Wallet addresses.
Blocks.
Gas fees.
Transaction status.

Example: Etherscan.

Confirm the recovery phrase.
Open the wallet dashboard.

PRACTICAL 13 – Bank Account Smart Contract using Solidity
1. Aim

Write and deploy a Smart Contract on an Ethereum test network for a customer's bank account with the following operations:

Deposit Money.
Withdraw Money.
Show Balance.
2. What is Blockchain?

Blockchain is a distributed digital ledger that stores data in blocks connected through cryptographic hashes.

It provides transparency, security and resistance to unauthorized modification.

3. What is Ethereum?

Ethereum is a decentralized blockchain platform that supports smart contracts and decentralized applications.

4. What is a Smart Contract?

A Smart Contract is a program stored on a blockchain that automatically executes according to predefined conditions.

5. What is Solidity?

Solidity is a high-level, statically typed programming language used to write smart contracts for Ethereum-compatible blockchains.

6. What is EVM?

EVM stands for Ethereum Virtual Machine.

It is the execution environment responsible for executing smart contract bytecode.

7. What is Remix IDE?

Remix IDE is a browser-based development environment used to write, compile, test and deploy Solidity smart contracts.

8. What are the Important Solidity Keywords?

pragma:

Specifies the compiler version.

contract:

Defines a smart contract.

mapping:

Stores data in key-value pairs.

function:

Defines an operation.

payable:

Allows a function to receive Ether.

require():

Checks a condition and reverts execution if the condition is false.

msg.sender:

Represents the account or contract that directly called the function.

msg.value:

Represents the amount of Ether sent with the transaction.

9. Understanding the Bank Account Contract

The contract performs three major operations.

Deposit:

Allows the user to send Ether to the contract.

The contract increases the user's recorded balance.

Withdraw:

Allows the user to withdraw Ether from their recorded balance.

It checks whether sufficient balance is available.

Show Balance:

Displays the user's recorded balance.

10. How Does the Contract Work?

Suppose a customer deposits 2 ETH.

The contract records:

Balance = 2 ETH.

The customer withdraws 1 ETH.

Updated balance:

Balance = 1 ETH.

If the customer tries to withdraw 2 ETH, the transaction fails because the balance is insufficient.

11. Algorithm
Start.
Write the Solidity smart contract.
Declare the required variables or mappings.
Create the deposit function.
Create the withdrawal function.
Create the balance display function.
Compile the contract.
Connect to an Ethereum-compatible test network.
Deploy the contract.
Call the deposit function.
Call the withdrawal function.
Check the balance.
Stop.
12. What is Deployment?

Deployment is the process of publishing compiled smart contract bytecode to a blockchain network.

13. What is Gas?

Gas measures the computational work required to execute smart contract operations.

14. What is a Constructor?

A Constructor is a special function that executes once when a contract is deployed.

1. Aim

2. What is Blockchain?

Blockchain is a distributed ledger that stores information in cryptographically connected blocks.

It provides secure and transparent record-keeping.

3. Types of Blockchain

There are four commonly discussed categories:

Public Blockchain.
Private Blockchain.
Consortium Blockchain.
Hybrid Blockchain.
4. Public Blockchain

A Public Blockchain is an open network where anyone can participate according to the protocol rules.

Characteristics:

Open participation.
Decentralized control.
Transparency.
Distributed consensus.

Examples:

Bitcoin.
Ethereum.

Applications:

Cryptocurrency.
Decentralized Finance.
NFTs.
5. Private Blockchain

A Private Blockchain is controlled by a single organization.

Participation is restricted to authorized users.

Characteristics:

Restricted access.
Centralized organizational control.
Faster processing may be possible.
Greater privacy within the network.

Applications:

Enterprise record management.
Internal supply chains.
Private financial systems.
6. Consortium Blockchain

A Consortium Blockchain is controlled by multiple organizations.

It is also called a Federated Blockchain.

Characteristics:

Multiple controlling organizations.
Permissioned access.
Shared decision-making.
Suitable for collaboration.

Applications:

Banking.
Supply chain management.
Inter-organizational data sharing.
7. Hybrid Blockchain

A Hybrid Blockchain combines public and private blockchain features.

Some data is private, while selected information can be made publicly verifiable.

Applications:

Government services.
Healthcare.
Enterprise record management.
8. Comparison of Blockchain Types

Public:
Anyone can participate. Example: Bitcoin.

Private:
One organization controls access. Example: Private Hyperledger Fabric deployment.

Consortium:
Multiple organizations share control. Example: A banking consortium.

Hybrid:
Combines public and private features.

9. Real-Time Blockchain Applications

Medical record integrity, medicine tracking and secure data sharing.

Government:

Land records, digital identity and certificate verification.

Retail:

PRACTICAL 15 – Create a Business Network using Hyperledger
1. Aim

Create a Business Network using Hyperledger.

2. What is Hyperledger?

Hyperledger is an open-source collaborative project hosted by the Linux Foundation.

It provides frameworks and tools for developing enterprise blockchain solutions.

3. What is Hyperledger Fabric?

Hyperledger Fabric is a permissioned blockchain framework designed for enterprise applications.

It allows organizations to create blockchain networks with controlled access.

4. What is a Business Network?

A Business Network is a group of organizations that interact and exchange information or transactions.

Example:

A supply chain network involving:

Manufacturer.
Distributor.
Retailer.
Customer.
5. What is Hyperledger Fabric Architecture?

Important components:

1. Peer:

A node that maintains ledger data and can execute or validate transactions.

2. Orderer:

The ordering service establishes the order of transactions and packages them into blocks.

3. Channel:

A private communication and transaction space between selected network members.

4. Ledger:

Stores blockchain records and the current world state.

5. Chaincode:

The smart contract logic used to implement business rules.

6. Certificate Authority:

Issues and manages digital identities for network participants.

6. What is a Peer?

A Peer is a node in Hyperledger Fabric that maintains a copy of the ledger and participates in transaction processing.

7. What is an Orderer?

An Orderer is a component responsible for ordering transactions into blocks.

8. What is Chaincode?

Chaincode is the smart contract program in Hyperledger Fabric.

It defines the business rules and operations of the network.

9. What is a Channel?

A Channel is a private communication and transaction mechanism that allows selected organizations to maintain a separate ledger.

10. What is a Ledger?

A Ledger is a record of transactions maintained by the blockchain network.

In Hyperledger Fabric, it includes:

Blockchain – Transaction history.
World State – Latest values of ledger data.
11. What is MSP?

MSP stands for Membership Service Provider.

It defines how identities are recognized and authenticated in a Hyperledger Fabric network.

12. What is Endorsement Policy?

An Endorsement Policy defines which organizations or peers must approve a transaction before it can be committed.

13. What is a Transaction Flow in Hyperledger Fabric?
Client submits a transaction proposal.
Required endorsing peers simulate the transaction.
Endorsing peers return signed endorsements.
The client submits the transaction to the ordering service.
The orderer orders transactions into blocks.
Peers validate the transactions.
Valid transactions are committed to the ledger.
14. Steps to Create a Business Network

At a conceptual level:

Install Hyperledger Fabric prerequisites.
Set up the development environment.
Create the required organizations.
Configure network identities.
Create peers and ordering service.
Create a channel.
Deploy chaincode.
Submit transactions.
Verify ledger updates.
15. What is the Difference Between Ethereum and Hyperledger Fabric?

Ethereum:

Public blockchain by default.
Supports permissionless participation.
Uses Solidity for many smart contracts.
Native cryptocurrency is Ether.

Hyperledger Fabric:

Permissioned blockchain framework.
Designed for enterprise networks.
Supports controlled identities.
Does not require a native cryptocurrency.
