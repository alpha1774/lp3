UNIT I – Mathematical Foundation for Blockchain
Part A: Important Theory Questions and Answers

Q1. What is Cryptography?

Answer:

Cryptography is the technique of securing information by converting readable data (plaintext) into an unreadable format (ciphertext).

It protects information from unauthorized access and ensures secure communication.

Main objectives:

Confidentiality – Protects information from unauthorized users.
Integrity – Ensures data is not modified.
Authentication – Verifies the identity of users.
Non-repudiation – Prevents users from denying their actions.
Q2. What are the types of Cryptography?

Answer:

There are two main types of cryptography:

Symmetric Key Cryptography.
Asymmetric Key Cryptography.

Symmetric cryptography uses the same key for encryption and decryption, whereas asymmetric cryptography uses a public key and a private key.

Q3. What is Symmetric Key Cryptography?

Answer:

Symmetric Key Cryptography is an encryption technique in which the same secret key is used for both encryption and decryption.

The sender and receiver must securely share the secret key.

Examples:

AES.
DES.
3DES.

Advantages:

Fast encryption and decryption.
Suitable for large amounts of data.
Requires less computational power.

Disadvantages:

Secure key sharing is difficult.
Key management becomes complex when many users communicate.
Q4. What is Asymmetric Key Cryptography?

Answer:

Asymmetric Key Cryptography is an encryption technique that uses two different keys:

Public Key – Shared openly with others.
Private Key – Kept secret by the owner.

Data encrypted using a recipient's public key can be decrypted using the corresponding private key.

It is also used for digital signatures.

Examples:

RSA.
ECC.
DSA.

Advantages:

Solves the problem of sharing secret encryption keys.
Supports digital signatures.
Provides authentication and non-repudiation.

Disadvantages:

Slower than symmetric encryption.
Requires more computational resources.
Q5. Differentiate between Symmetric and Asymmetric Cryptography.

Answer:

Symmetric Cryptography:

Uses one secret key.
Same key is used for encryption and decryption.
Faster processing.
Key sharing is difficult.
Example: AES.

Asymmetric Cryptography:

Uses two keys: public and private.
Different keys are used for encryption and decryption.
Generally slower.
Public key can be shared openly.
Example: RSA and ECC.
Q6. What is Elliptic Curve Cryptography (ECC)?

Answer:

Elliptic Curve Cryptography is an asymmetric cryptographic technique based on the mathematical properties of elliptic curves over finite fields.

It provides strong security using comparatively smaller key sizes.

Advantages:

Smaller key size.
Faster operations in many implementations.
Less memory requirement.
Suitable for mobile and IoT devices.

Application: Bitcoin uses Elliptic Curve Cryptography for digital signatures.

Q7. What is a Cryptographic Hash Function?

Answer:

A Cryptographic Hash Function is a mathematical function that converts input data of any size into a fixed-length output called a hash value or digest.

Properties:

Fixed-length output.
One-way function.
Difficult to find two inputs with the same hash.
Small input changes produce significantly different hashes.
Fast computation.

Examples: SHA-256 and SHA-3.

Q8. What is SHA-256?

Answer:

SHA-256 stands for Secure Hash Algorithm 256-bit.

It is a cryptographic hash function that converts input data into a fixed 256-bit hash value.

It is widely used in blockchain for:

Transaction verification.
Block identification.
Data integrity.
Proof of Work mining.

Important: SHA-256 produces a 256-bit hash, which is represented as 64 hexadecimal characters.

Q9. What is a Digital Signature?

Answer:

A Digital Signature is a cryptographic technique used to verify the authenticity and integrity of a digital message or transaction.

It is created using the sender's private key and verified using the corresponding public key.

Working:

The sender creates a hash of the message.
The sender signs the hash using their private key.
The receiver gets the message and digital signature.
The receiver verifies the signature using the sender's public key.

Advantages:

Authentication.
Integrity.
Non-repudiation.
Q10. What is Digital Signature Algorithm (DSA)?

Answer:

DSA stands for Digital Signature Algorithm.

It is a public-key cryptographic algorithm used to generate and verify digital signatures.

It helps ensure that a message comes from the claimed sender and has not been modified.

DSA is designed for digital signatures, not for encrypting messages.

Q11. What is a Merkle Tree?

Answer:

A Merkle Tree is a tree-like data structure used in blockchain to efficiently verify the integrity of data.

It is constructed by:

Generating hashes of individual transactions.
Combining pairs of hashes.
Hashing the combined values.
Repeating the process until one hash remains.

The final hash is called the Merkle Root.

Advantages:

Efficient transaction verification.
Detects data modification.
Reduces storage and verification requirements.
Q12. What is a Merkle Root?

Answer:

A Merkle Root is the final hash at the top of a Merkle Tree.

It represents all transactions included in that tree.

If even one transaction changes, the Merkle Root also changes.

Q13. What is the difference between Hashing and Encryption?

Answer:

Hashing:

Converts data into a fixed-length hash.
Generally irreversible.
Used for integrity verification.
Example: SHA-256.

Encryption:

Converts readable data into ciphertext.
Reversible using the appropriate decryption key.
Used for confidentiality.
Example: AES.

Answer: Plaintext is the original readable message before encryption.

Q15. What is ciphertext?

Answer: Ciphertext is the unreadable encrypted form of the original message.

Q16. What is encryption?

Answer: Encryption is the process of converting plaintext into ciphertext.

Q17. What is decryption?

Q18. What is a public key?

Answer: A public key is a cryptographic key that can be shared openly with other users.

Q19. What is a private key?

Q20. Which cryptography is used in Bitcoin?

Answer: Bitcoin uses Elliptic Curve Cryptography for digital signatures and SHA-256 for hashing and mining-related operations.

Q21. What is the output size of SHA-256?

Answer: 256 bits or 32 bytes.

Q22. Can a hash be reversed?

Answer: No. Cryptographic hashing is designed to be a one-way process.

Q23. What happens if transaction data changes in a Merkle Tree?

Answer: The transaction hash and corresponding Merkle Root change.

Q24. What is collision resistance?

Answer: It is the property of a hash function that makes it computationally difficult to find two different inputs producing the same hash.

Q25. What is the purpose of a Digital Signature?

Answer: To verify the authenticity and integrity of digital information.

Part A: Important Theory Questions and Answers
Q1. What is Blockchain?

Answer:

Blockchain is a distributed digital ledger that stores information in blocks connected together using cryptographic hashes.

Each block contains transaction data, a timestamp and the hash of the previous block.

It provides transparency, security and resistance to unauthorized modification.

Q2. Explain the History of Blockchain.

Answer:

The development of blockchain took place in several stages:

1991 – Stuart Haber and W. Scott Stornetta introduced a cryptographically secured method for timestamping digital documents.
2008 – Satoshi Nakamoto published the Bitcoin whitepaper.
2009 – Bitcoin was launched as the first widely recognized decentralized cryptocurrency.
2015 – Ethereum introduced programmable smart contracts.
Present – Blockchain is used in banking, healthcare, supply chains, government and other industries.
Q3. What is a Centralized System?

Answer:

A Centralized System is a system in which all data and operations are controlled by a single central authority or organization.

Examples:

Traditional banking systems.
Centralized databases.
Government databases.

Advantages:

Easy management.
Faster decision-making.
Centralized control.

Disadvantages:

Single point of failure.
Greater dependency on central authority.
Risk of data manipulation.
Possible security breaches.
Q4. What is a Decentralized System?

Answer:

A Decentralized System is a system in which control and decision-making are distributed among multiple participants instead of being handled by a single central authority.

Examples:

Bitcoin.
Decentralized blockchain networks.

Advantages:

No single point of failure.
Greater transparency.
Distributed control.
Better resistance to censorship.
Q5. Differentiate between Centralized and Decentralized Systems.

Answer:

Centralized System:

Controlled by one central authority.
Data is managed centrally.
Single point of failure.
Requires trust in the central authority.

Decentralized System:

Control is distributed.
Data is maintained across multiple participants.
No single central point of failure.
Reduces dependency on a central authority.
Q6. Explain the Layers of Blockchain.

Answer:

Blockchain architecture consists of the following layers:

1. Application Layer:

This is the top layer where users interact with blockchain applications.

Example: Cryptocurrency wallets and decentralized applications.

2. Execution Layer:

It executes transactions and smart contracts.

Example: Ethereum Virtual Machine.

3. Semantic Layer:

It defines the meaning and interpretation of transactions, smart contracts and blockchain data.

4. Propagation Layer:

It is responsible for distributing transactions and blocks between network nodes.

5. Consensus Layer:

It helps network participants agree on the valid state of the blockchain.

Example: Proof of Work and Proof of Stake.

Q11. What is a Distributed Ledger?

Answer:

A Distributed Ledger is a digital database shared and maintained across multiple computers or nodes in a network.

Every authorized participant can maintain a copy of the ledger.

Blockchain is one type of Distributed Ledger Technology (DLT).

Q12. What is a Node in Blockchain?

Answer:

A Node is a computer or device participating in a blockchain network.

It may store blockchain data, validate transactions or help communicate information between participants.

Q13. What is a Block?

Answer:

A Block is a data structure that stores a collection of verified transactions.

A typical blockchain block contains:

Block Header.
Transaction Data.
Previous Block Hash.
Timestamp.
Nonce or other consensus-related information.
Q14. What is a Genesis Block?

Answer:

The Genesis Block is the first block of a blockchain.

It is also known as Block 0 and does not have a previous block in the chain.

Q15. What is Immutability in Blockchain?

Answer:

Immutability means that once information is confirmed and added to the blockchain, changing it becomes extremely difficult.

This is achieved through cryptographic hashing and distributed consensus.

Q2. Explain the Types of Blockchain Platforms.

Answer:

There are three major types of blockchain networks:

1. Public Blockchain:

A public blockchain is an open network where anyone can participate and verify transactions according to the network rules.

Examples: Bitcoin and Ethereum.

2. Private Blockchain:

A private blockchain is controlled by a single organization. Only authorized users can participate.

3. Consortium Blockchain:

A consortium blockchain is managed by multiple organizations instead of a single organization.

Example: A blockchain network jointly managed by multiple banks.

Q4. What is Bitcoin?

Answer:

Bitcoin is a decentralized digital cryptocurrency introduced by Satoshi Nakamoto in 2009.

Q10. What is Consensus in Blockchain?

Answer:

Consensus is the process through which blockchain network participants agree on the validity and order of transactions.

It ensures that all participating nodes maintain a consistent ledger state.

Q11. Why is Consensus Important in Blockchain?

Answer:

Consensus is important because it:

Prevents double spending.
Maintains agreement between nodes.
Validates transactions.
Prevents unauthorized changes.
Maintains network security.
Q12. What are the Elements of Consensus?

Answer:

Important elements of a blockchain consensus mechanism include:

Nodes – Participants in the network.
Transactions – Operations submitted to the network.
Validation – Checking transaction correctness.
Agreement – Reaching a common decision.
Finality – Determining when a transaction is considered confirmed and irreversible under the protocol.
Q13. What is a Consensus Algorithm?

Answer:

A Consensus Algorithm is a set of rules that helps distributed network participants agree on the valid state of the blockchain.

Examples:

Proof of Work.
Proof of Stake.
Proof of Elapsed Time.
Proof of Activity.
Proof of Burn.
Q14. What is Proof of Work (PoW)?

Answer:

Proof of Work is a blockchain consensus mechanism in which miners compete to solve a difficult mathematical puzzle.

The first miner to find a valid solution can propose the next block, which is then validated by the network.

Advantages:

Strong security.
Resistant to certain attacks.
Proven in Bitcoin.

Disadvantages:

High energy consumption.
Requires computational power.
Can have limited transaction throughput.
Q15. What is Proof of Stake (PoS)?

Answer:

Proof of Stake is a consensus mechanism in which validators are selected to propose and validate blocks based partly on the cryptocurrency they stake.

Validators lock cryptocurrency as a stake and may lose part of it if they violate protocol rules.

Advantages:

Low energy consumption.
No mining competition.
Energy-efficient.

Disadvantages:

Requires cryptocurrency staking.
Wealth concentration can be a concern.
Requires mechanisms to prevent malicious validators.
Q16. What is Proof of Elapsed Time (PoET)?

Answer:

Proof of Elapsed Time is a consensus mechanism in which participating nodes wait for randomly assigned time periods.

The node whose waiting period finishes first gets the opportunity to create the next block.

It is associated with trusted execution environments such as Intel SGX.

Q17. What is Proof of Activity?

Answer:

Proof of Activity is a hybrid consensus mechanism that combines Proof of Work and Proof of Stake.

It uses mining to create a block template and stakeholders to help validate and complete the block.

It combines ideas from both consensus mechanisms.

Q18. What is Proof of Burn?

Answer:

Proof of Burn is a consensus mechanism in which participants permanently destroy or send cryptocurrency to an unspendable address to demonstrate commitment to the network.

Burned coins cannot be recovered or spent.

Q19. What is the Byzantine Generals Problem?

Answer:

The Byzantine Generals Problem is a computer science problem that explains how distributed systems can reach agreement even when some participants behave maliciously or send incorrect information.

It demonstrates the difficulty of achieving reliable consensus in an unreliable network.

Q20. Explain the Byzantine Generals Problem Scenario.

Answer:

Imagine several army generals surrounding a city.

They must agree whether to attack or retreat.

However, they communicate through messengers, and some generals may be traitors who send false messages.

The challenge is to ensure that all loyal generals reach the same decision despite the presence of dishonest participants.

This problem represents the challenge of achieving consensus in distributed systems.

Q21. What is Byzantine Fault Tolerance (BFT)?

Answer:

Byzantine Fault Tolerance is the ability of a distributed system to continue operating correctly even when some nodes behave maliciously or provide incorrect information.

It helps blockchain networks achieve reliable consensus.

Proof of Stake:

Uses cryptocurrency staking.
Validators are selected to propose blocks.
Consumes less electricity.
